Request & Data Flow

User changes a filter
FilterBar.vue binds dropdowns to shared reactive refs exposed by the filters composable.
View watches filter state
Each view (Dashboard.vue, Orders.vue, etc.) watches the composable refs and triggers a reload.
API client builds request
api.js converts the filter object into URLSearchParams, dropping any values set to 'all', then calls Axios.
HTTP request crosses to backend
GET http://localhost:8001/api/orders?warehouse=WH-01&month=2025-03 — CORS middleware allows the cross-origin call.
FastAPI filters in-memory data
Endpoint reads from module-level lists loaded at startup. apply_filters() runs warehouse/category/status list comprehensions, then filter_by_month() handles month or quarter matching.
Pydantic validates the response
response_model=List[Order] enforces schema on the way out. Mismatched JSON fields fail here — not silently at the client.
Vue computed properties derive display data
Raw results land in a ref. Computed properties derive totals, groupings, and chart series — cached until dependencies change.
Reactive DOM update
Vue's reactivity system patches only the DOM nodes that changed. Tables and SVG charts re-render automatically.
